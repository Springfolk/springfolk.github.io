# springfolk.github.io

<https://springfolk.github.io/> redirects to Springfolk's GitHub organisation, <https://github.com/Springfolk>: the project index lives there now. Project sites keep their own paths (e.g. <https://springfolk.github.io/alaas-game/>, served from its own repo). Commercial work lives at [springfolk.co](https://springfolk.co).

- `index.html` — instant redirect (meta refresh + `location.replace`, a plain link as fallback).
- `404.html` — a missing page goes to its project's repo (`/alaas-game/…` → `github.com/Springfolk/alaas-game`), else the organisation.

Rules: keep it within GitHub's [Pages limits](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits) and [Acceptable Use Policies](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies) — no trackers, ads or third-party scripts; the only redirect is to Springfolk's own pages on github.com.
