# springfolk.github.io

Index of Springfolk's non-commercial open-source projects, served by GitHub Pages at <https://springfolk.github.io/>. Commercial work lives at [springfolk.co](https://springfolk.co).

Plain static HTML + CSS, no build step: edit `index.html` and push to `main`.

## Rules for every edit

This site must stay within GitHub's [Pages limits](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits) and [Acceptable Use Policies](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies).

- Non-commercial: no selling, prices, ads, store, checkout or donation pitches. A plain link to springfolk.co is fine.
- No trackers, analytics, third-party scripts, forms, data collection or cookies. All fonts and images are self-hosted.
- No redirects to external sites, URL shorteners, hidden content or keyword stuffing; no third-party branding.
- Small and static: no large binaries (the whole site is well under 1 MB).
- Descriptions must be accurate: no claims a project doesn't live up to.
- Brand: colours and logo files only as `Springfolk/branding` specifies; copy SVG masters, never edit them.
