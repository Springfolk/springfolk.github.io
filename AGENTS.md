# springfolk.github.io

A redirect only: `index.html` sends <https://springfolk.github.io/> to <https://github.com/Springfolk>; `404.html` sends a missing page to its project's repo (else the organisation). GitHub Pages from `main`, root; no build. Project sites (`/alaas-game/`) are served from their own repos and are unaffected. Rules: `README.md`.
