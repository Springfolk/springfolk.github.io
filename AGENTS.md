# springfolk.github.io

Static index of Springfolk's non-commercial open-source projects (GitHub Pages, repo `Springfolk/springfolk.github.io`, branch `main`, served from the root). No build, no JS.

- Preview: `python3 -m http.server` in the repo root (404.html uses root-absolute paths).
- **Before any edit read the rules in `README.md`** (GitHub Pages / acceptable-use: no commerce, tracking, scripts, redirects, large files).
- Brand source of truth: `Springfolk/branding` (`~/Development/GameDev/springfolk-branding`). Never write green text; never edit the copied SVGs.
